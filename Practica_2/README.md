En esta práctica he estructurado un sistema de carpetas donde se tiene el objetivo de mantener un código limpio y legible.

Para ello, se han creados las siguientes carpteas:
```

/descriptors
/dataset_loader 
/ml_clasificators
/neural_networks
/figures
/results
```

En cada una de las carpetas se incluye las funciones relacionadas con la asignatura y el concepto de la carpeta.

Como el objetivo de la práctica es crear clasificadores empleando modelos de ML como SVM que utilizarán la información de los descriptores como entrada o arquitecturas de NN, se han creado dos Notebooks principales uno para cada escenario y otro final para comparar los resultados:
```
1_Clasificadores_descriptores_ML.ipynb
2_Clasificadores_NN.ipynb
3_Results.ipynb
```
